# Chronicles of Bilal — 3D Storytelling Developer Portfolio World

An interactive, physically-lit **3D Minecraft Spring Storytelling World** built for **Mohammed Bilal A**—powered by **React 19**, **Three.js / React Three Fiber v9**, **Rapier 3D WASM Physics**, **Custom GLSL Shaders**, and **Tailwind CSS v4**.

## Key Features

- **Visitor Onboarding & Character Selection Gate**: Every visitor enters their name, selects a role badge, chooses from **6 Character Archetypes** (*Sakura Storyteller*, *AI Cyber Sentinel*, *Industrial Architect*, *Executive Talent Scout*, *Blossom Botanist*, *Hackathon Champion*), and customizes their **Hairstyle/Headgear** (Classic, Spiky, Ponytail, Studio Headphones, Cyber Visor, Sun Hat, Crown), **Outfit Cut** (Hoodie, Blazer, Cyber Vest, Tunic), **Back Gear** (Cape, Twin Jetpack, Backpack), and **Color Palette** before entering the 3D world.
- **Dedicated 3D Space — Sakura Style & Outfit Atelier**: Located on the West Blossom Courtyard (`[-19.5, 0, 1.5]`), featuring a holographic mirror arch, 3 rotating 3D mannequin podiums (with the center podium mirroring the visitor's live outfit), and an interactive proximity pad (`[C]` or `[Enter]`) to change character style and outfit anytime.
- **Resume-Driven 3D Storytelling Concept World**: Chronicles **Mohammed Bilal A**’s journey across **6 Interactive Story Chapters**:
  1. **Chapter I — The Industrial Frontier**: *THOZHIRPORUL Smart Industrial Monitoring System* (`React.js`, `Node.js`, `Express.js`, `PostgreSQL`, `Docker`, GIS park mapping & AI governance)
  2. **Chapter II — The AI Security Bastion**: *Dual-Layer AI Firewall for Securing LLM Applications* (`Python`, `FastAPI`, `XGBoost`, `PostgreSQL`, `Docker` prompt-injection defense)
  3. **Chapter III — The FinTech ML Vault**: *Credit Card Fraud Detection ML Engine* (`Python`, `Scikit-learn`, `Pandas`, `NumPy` behavioral transaction classification)
  4. **Chapter IV — The E-Learning Guild**: *Sasha Infinity Web Developer Internship (Jun 2025 – Present)* (`WordPress`, `Tutor LMS`, `REST APIs`, AI-tool integration)
  5. **Chapter V — The Academic Citadel**: *Sona College of Technology (MCA, 8.3 CGPA) & Sona College of Arts & Science (BCA, 7.9 CGPA)*
  6. **Chapter VI — Hall of Champions**: *Winner SIF Pitch Fest 2026, Finalist SDG Hackathon 2026, SIH 2025 Qualifier, Top 500 Niral Thiruvizha 3.0 & 7 Certifications (including NPTEL Java Elite + Gold)*
- **Manual Project Storage & 3D Pavilion Spawner**: Click **`+ Add Project`** in the HUD or Directory to manually add, edit, or delete portfolio projects. Projects persist automatically in `localStorage` and spawn live 3D Pavilions in the world complete with animated 640×360 3D display screens, NPC specialist guides, Story Quest chapters, and Minimap teleport pins.
- **3 Driveable Spring Vehicles & Articulated Seated Kinematics**: Drive the `[1]` **Sakura Trail 4x4 Safari**, `[2]` **Blossom GT Roadster**, or `[3]` **Meadow Breeze Scooter** with your customized character seated behind the wheel.

## Quick Start

```bash
npm install
npm run dev
```

Open `http://127.0.0.1:5173/` or `http://localhost:5173/`.
